# NOVA FORGE HEAVY INDUSTRIES · 星铸重工

未来科幻重工业风格品牌落地页（自包含单文件 HTML）。

## 项目简介

虚构深空轨道工业集团「星铸重工 NOVA FORGE HEAVY INDUSTRIES」的品牌展示页：聚变供能、轨道铸造、星舰装甲、深空物流四大工业系统，天枢站 A / B / D 三大厂区，星历建站三阶段工程履历，以及入站申请演示表单。

## 页面结构

- 顶栏 + Hero（深空轨道工业站全景，HUD 遥测角标）
- 运营遥测：聚变机组 / 轨道节点 / 连续运转 / 年吞吐
- 四大工业系统卡片（SYS-01 ~ SYS-04）
- 轨道设施图卡：聚变反应堆核心（A 区）、轨道熔铸厂（B 区）、星舰装配坞（D 区）
- 工程履历时间轴（星历 01 / 07 / 13）
- 入站申请表单（演示模式，不真实提交）

## 技术说明

- 单文件自包含 HTML：CSS / JS 全部内联，4 张配图以 WEBP base64 内嵌，无外部依赖，离线可直接打开
- 字体：Orbitron（展示字）+ Rajdhani（数据标签）+ Noto Sans SC（正文），走自托管镜像
- 响应式：375px 移动端优先，适配桌面 / 平板 / 手机
- 页面全部品牌、数据、场景均为虚构，仅供视觉演示

## 使用

直接用浏览器打开 `星铸重工-未来科幻重工落地页.html` 即可。
